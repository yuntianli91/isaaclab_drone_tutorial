教程

欢迎阅读 Isaac Lab 教程！这些教程通过循序渐进的方式，帮助你理解并使用 Framework 的各项功能。所有教程均以 Python Script 编写；对应 Source Code 可在 Isaac Lab Repository 的 scripts/tutorials 目录中找到。

备注

我们希望不断扩充教程，涵盖更多主题与 Use Case。如果你有任何建议，欢迎告知我们。

建议按照这里列出的顺序阅读教程。

1 设置简单仿真

这些教程介绍如何使用不同设置启动 Simulation，以及如何在 Simulated Scene 中生成 Objects。教程涵盖以下 API： AppLauncher、 SimulationContext 和 spawners。

  • 创建空场景
  • 在 Scene 中生成 Prim
  • 深入了解 AppLauncher

2 与 Assets 交互

在 Scene 中生成 Objects 后，这些教程将介绍如何为它们创建 Physics Handles 并进行交互。相关内容围绕 AssetBase Class 及其派生类型展开， 包括 RigidObject、Articulation 和 DeformableObject。

  • 向 Isaac Lab 添加新 Robot
  • 与 Rigid Object 交互
  • 与 Articulation 交互
  • 与 Deformable Object 交互
  • 与 Surface Gripper 交互

3 创建 Scene

掌握 Framework 的基本概念后，教程将转向使用 InteractiveScene Class 的、更直观的 Scene Interface。该 Class 提供了更高层的 Abstraction，使创建 Scenes 更加容易。

  • 使用 Interactive Scene

4 设计 Environment

以下教程将介绍 Manager-Based Environments： ManagerBasedEnv 及其派生类 ManagerBasedRLEnv，以及 Direct Workflow Base Class DirectRLEnv。这些 Environments 将 Framework 的不同部分组合起来，创建供 Agent 交互的 Simulation Environment。

  • 创建 Manager-Based Base Environment
  • 创建 Manager-Based RL Environment
  • 创建 Direct Workflow RL Environment
  • 注册 Environment
  • 使用 RL Agent 训练
  • 配置 RL Agent
  • 修改现有 Direct RL Environment
  • USD Environment 中的 Policy Inference

5 集成 Sensors

以下教程介绍如何将 Sensors 集成到 Simulation Environment 中，并引入 SensorBase Class 及其派生类型，例如 Camera 和 RayCaster。

  • 在 Robot 上添加 Sensors

6 使用 Motion Generators

除了在 Joint-Level 控制 Robots，以下教程还将介绍如何使用 Motion Generators 在 Task-Level 控制 Robots。

  • 使用 Task-Space Controller
  • 使用 Operational Space Controller
