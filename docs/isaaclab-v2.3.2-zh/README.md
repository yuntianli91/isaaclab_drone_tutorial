# Isaac Lab v2.3.2 中文教程

本目录是 Isaac Lab v2.3.2 官方 Tutorials 的非官方中文翻译。

## 翻译范围

- 教程首页。
- 官方 v2.3.2 Tutorials 中的全部 20 篇教程。
- 教程引用的图片、代码、页面导航和页内目录。

## 查看方式

在本目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问 `http://127.0.0.1:8000/`。

也可以直接在浏览器中打开 `index.html`。主题切换和目录过滤功能可直接使用，
但复制按钮可能受到浏览器对本地文件的权限限制。

## 翻译约定

- Isaac Lab、Isaac Sim、Omniverse 相关概念与 API 名称尽量保留英文。
- 正文中保留的英文术语采用首字母大写形式，并使用独立颜色强调。
- 所有 inline code、独立 code block 和 command 均保持英文原文及原始格式。
- Inline code 使用高对比度背景、边框和文字颜色，与普通正文区分。
- 独立代码块标注 Python 或 Bash，并在本地执行对应的 syntax highlighting。
- 可运行 source code 不作翻译或改写。
- 原文版本固定为 v2.3.2，译文不混用其他版本内容。
